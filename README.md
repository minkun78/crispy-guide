# crispy-guide

A tiny example project used for practicing the GitHub pull request workflow.

## What's here

`calculator.py` is a small module with four basic arithmetic functions:

- `add(a, b)`
- `subtract(a, b)`
- `multiply(a, b)`
- `divide(a, b)` (raises `ValueError` on division by zero)

## Running the tests

```bash
python -m unittest test_calculator.py
```
